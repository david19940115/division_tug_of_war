# 除法拔河大挑戰

適合國小四年級「整數的除」單元的雙隊觸控網頁遊戲。

## 使用方式

直接開啟 `index.html` 即可遊玩，不需安裝任何程式，也不需要網路連線。

線上遊玩：https://david19940115.github.io/division_tug_of_war/

## 遊戲規則

- 題型隨機出現：四位數除以一位數、二位數除以二位數、三位數除以二位數、四位數除以二位數。
- 有餘數與沒餘數各以約一半機率隨機出現，餘數小於除數。
- 有餘數時先輸入商，按「餘數」鍵顯示「...」，再輸入餘數，例如 `23...5`。沒餘數時只輸入商（也接受 `23...0`）。
- 「清除」逐位刪除；餘數刪完後再按一次會移除「...」。鍵盤的句點鍵也可輸入餘數分隔符號。
- 直接答對得 2 分；答錯後再答對得 1 分。
- 同一題答錯 3 次會顯示正確答案，換下一題且不加分。
- 每場開始前由老師輸入 1～60 分鐘的比賽時間，時間到時分數較高的隊伍獲勝。
- 兩隊名稱為「小寶隊」與「小貝隊」。
- 每隊由一隻步行皮克敏，以及一隻騎著歐慶的皮克敏參賽。
- 所有選手會以手部位置對齊拔河繩，不以腳底高度排齊。
- 騎乘組合由歐慶的兩隻前腳負責拔繩，皮克敏的雙手扶著歐慶的背帶。
- 桌面版會依瀏覽器可視高度自動壓縮，無需進入 F11 全螢幕即可完整顯示。
- 當兩隊分差達 15 分時，落後隊的繩上圓點會碰到中線並提前結束比賽。

## 素材說明

角色是依照使用者提供的植物小生物參考圖所製作的原創 AI 插畫，不使用原圖作為遊戲素材。
